## 📋 Описание

**Jarvis** — это персональный голосовой ассистент, который обеспечивает полную конфиденциальность, так как все вычисления (распознавание, генерация текста и озвучка) происходят локально на вашем компьютере.

### Ключевые возможности:
*   🎙️ **Локальное распознавание речи:** Использование быстрых и легковесных моделей через **Vosk**.
*   🧠 **Умные ответы:** Интеграция с локальной LLM  через Ollama.
*   🗣️ **Синтез речи:** Озвучивание ответов в реальном времени с помощью **pyttsx3**.
*   🎨 **Графический интерфейс:** Удобное управление настройками на базе **PySide6**.

## ⚙️ Установка и настройка

### 1. Подготовка Ollama

1. Скачайте и установите [Ollama](https://ollama.com).
2. Запустите терминал и загрузите подходящую вам модель:

```bash
   ollama run *название_модели*

```

### 2. Загрузка модели распознавания речи (STT)

1. Перейдите на сайт [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models).
2. Скачайте подходящую русскую модель (например, `vosk-model-small-ru-0.22` для экономии ресурсов или полную версию для лучшего качества).
3. Распакуйте содержимое архива в папку `model/` в корневом каталоге проекта.

### 3. Установка зависимостей Python

Убедитесь, что у вас установлен Python 3.10 или новее, затем выполните команду:

```bash
pip install requests vosk sounddevice pyttsx3 PySide6 pyautogui

```

## 🎙 Режимы работы

Ассистент может переключаться между двумя основными контекстами:

| Режим | Описание | Голосовая команда для активации |
| --- | --- | --- |
| **MODE_AI** | Свободное общение и ответы на вопросы через LLM. | `«режим ИИ»` / `«назад»` |
| **MODE_APPS** | Управление операционной системой и программами. | `«режим приложений»` |

## 🗣 Таблица доступных команд

### Системные и мультимедиа

* `«открой хром»` / `«открой ютуб»` / `«открой телеграм»` — запуск веб-ресурсов и приложений.
* `«открой блокнот»` / `«открой калькулятор»` / `«открой проводник»` — запуск стандартных утилит.
* `«включи музыку [название] на ютубе»` — автоматический поиск и воспроизведение.
* `«запусти олламу»` — принудительный старт локального сервера Ollama.

### Управление окнами (Windows)

* `«закрой вкладку»` — эмуляция `Ctrl + W`.
* `«закрой окно»` — эмуляция `Alt + F4`.
* `«сверни»` — сворачивает активное окно (`Win + Down`).
* `«сверни все»` — скрывает все окна и показывает рабочий стол (`Win + D`).
* `«следующее окно»` / `«предыдущее окно»` — навигация по запущенным приложениям через `Alt + Tab`.

### Сервисные команды

* `«очисти корзину»` — быстрая очистка корзины Windows.
* `«что ты умеешь»` — голосовое перечисление основных функций.
* `«стоп»` / `«выход»` / `«пока»` — корректное завершение работы скрипта.

## ⚙️ Конфигурация (`jarvis_config.json`)

Вы можете править настройки вручную в файле или использовать вкладки GUI (**CORE**, **APPS MAP**, **WORDS**). Пример структуры:

```json
{
  "model_name": "deepseek-r1:8b",
  "ollama_address": "http://localhost:11434",
  "mode": "ai",
  "wake_word": "джарвис",
  "app_map": {
    "ютуб": "[https://www.youtube.com/](https://www.youtube.com/)",
    "блокнот": "notepad.exe"
  },
  "noise_words": ["пожалуйста", "давай", "ну"],
  "stop_words": ["стоп", "выход", "пока"]
}

```
